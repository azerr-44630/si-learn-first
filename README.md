# SI-Learn-First

Termux və yerli mühitlər üçün modulyar təhlükəsizlik və analiz agenti.

## Xüsusiyyətlər
- Modulyar skill arxitekturası (`skills/`)
- GitHub OSINT və repo təhlili
- Yerli kod, asılılıq və mühit auditi
- HTML/JSON hesabat generasiyası

## Quraşdırma
```bash
git clone https://github.com/azerr-44630/si-learn-first.git
cd si-learn-first
pip install -r requirements.txt
cp .env.example .env
```

## İstifadə
```bash
python main.py
```

Alətləri yalnız öz sistemlərinizdə və ya yazılı icazəniz olan hədəflərdə istifadə edin.
